# FunDLC — Avatar update

В этой версии личного кабинета добавлена смена аватара.

- Новый аккаунт получает `avatar-default.jpg` по умолчанию.
- В кабинете есть кнопки «Изменить аватар» и «По умолчанию».
- PNG/JPG/WebP можно выбрать с компьютера.
- Картинка автоматически уменьшается до 256 px и сохраняется в записи аккаунта.
- Данные аккаунта и аватар хранятся в локальной базе браузера (`localStorage`).
- Версия совместима с GitHub Pages.

## Важно про настоящую серверную БД
GitHub Pages не выполняет PHP и не предоставляет серверную БД. Поэтому эта версия хранит данные локально в браузере. Чтобы один и тот же аккаунт и аватар были доступны на разных устройствах/браузерах, FunDLC нужно подключить к PHP/Node.js API + MySQL/PostgreSQL/Supabase и сохранять `avatar` на сервере.
