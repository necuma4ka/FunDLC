# FunDLC — GitHub Pages

Готовая статическая версия FunDLC.

- PHP/API не используется.
- Вход сохраняется в браузере на 31 день.
- После перезагрузки страницы аккаунт восстанавливается автоматически.
- Кнопка «Выйти» удаляет сохранённую сессию.
- Личный кабинет открывается как полноэкранная страница.
- Название вкладки: `FunDLC — Minecraft Client`.
- UUID: 001, 002, 003, ... 010, 100 и далее.

Важно: GitHub Pages не выполняет PHP и не может надёжно проверять смену внешнего IP. Для проверки IP нужен серверный backend.
