# FunDLC — GitHub Pages

Готовая статическая версия сайта для GitHub Pages.

Файлы:
- `index.html` — сайт
- `minecraft.ttf` — Minecraft-шрифт

Регистрация и вход в этой версии работают без PHP через `localStorage` браузера.

Важно: это подходит для демонстрации/локального проекта. Данные аккаунтов хранятся в браузере пользователя и НЕ являются безопасной серверной системой авторизации. Для настоящих аккаунтов нужен отдельный backend.
