# FunDLC — GitHub Pages

Полноэкранный личный кабинет, Minecraft-шрифт и последовательный UUID: 001, 002, 003...


### Автовход
После успешного входа аккаунт запоминается в браузере на 31 день. Повторный вход не требуется, пока срок не истёк или пользователь не нажал «Выйти».

> Важно: определять смену внешнего IP надёжно только средствами GitHub Pages невозможно. Для требования «вход заново при смене IP» нужен серверный backend, который проверяет IP и хранит сессию.
