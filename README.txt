FunDLC — исправленная регистрация и авторизация

Что исправлено:
- Исправлен путь к api.php: он строится относительно текущей страницы и работает в подпапке.
- Убрана ситуация, когда обычная сетевая ошибка превращается в непонятное "Failed to fetch".
- Проверяется, что api.php действительно возвращает JSON.
- Для проверки сессии используется GET /api.php?action=me.
- Добавлен index.php для нормального запуска сайта через PHP.
- Сессия PHP настроена с HttpOnly/SameSite cookie.
- Пароли по-прежнему хранятся только через password_hash().

ВАЖНО:
1. Распакуй архив на PHP-хостинг (PHP 8.1+).
2. Открывай index.php через http:// или https://.
3. НЕ открывай FunDLC_site.html двойным кликом через file://.
4. api.php, accounts.json, index.php и FunDLC_site.html должны находиться в одной папке.
5. accounts.json должен быть доступен PHP на запись.

- Заголовок «Личный кабинет» использует Minecraft-шрифт из папки проекта.

- В этой версии Minecraft-шрифт принудительно применяется ко ВСЕМ HTML-элементам через !important.
